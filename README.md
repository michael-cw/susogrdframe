## Overview

`susogrdframe` is part of the **Survey Solutions Spatial Sampling
Toolbox**, developed by the [Joint Development Center
(JDC)](https://www.worldbank.org/en/programs/joint-development-center)
at the World Bank. It provides a self-contained Shiny application that
supports **replacement frame generation** for surveys that were sampled
from a population-weighted spatial grid.

When a primary sampling unit (PSU) selected from a spatial grid needs to
be replaced (e.g. because it is inaccessible), this application
identifies valid adjacent replacement cells, packages the necessary
spatial resources (boundary shapefiles, basemap tiles), and bundles them
into a survey-ready download for the field team.

### How it fits into the workflow

    Spatial Sampling App          susogrdframe
    ─────────────────────         ──────────────────────────────────────
    1. Define study area     →    4. Load saved boundary + raster files
    2. Overlay raster grid   →    5. Select stratum & grid cell
    3. Draw PSU sample       →    6. Generate replacement resources
                                  7. Download ZIP for Survey Solutions

### Key capabilities

| Feature | Description |
|----|----|
| **Dual storage backend** | Read/write from a **PostgreSQL/PostGIS** database *or* a **local directory** — no database required for offline use |
| **Interactive map** | Built on [deck.gl](https://deck.gl) via `mapdeck`, showing boundary layers, raster population grids, and selected cells in real time |
| **Stratum-aware selection** | Boundary files can contain multiple strata; the app filters the raster grid to the selected stratum only |
| **Segment splitting** | Optionally split a grid cell into 2 × 2, 3 × 3 or 4 × 4 sub-segments (useful for large PSUs) |
| **Basemap packaging** | Attach an offline basemap to the download — supports ESRI World Imagery, OpenStreetMap, Mapbox, Bing, and ESRI Tile Packages (.tpk) |
| **Survey Solutions output** | Produces a ZIP containing ESRI Shapefiles and a GPS coordinate file (centre + bounding rectangle) ready for direct upload to Survey Solutions |

## Quick start

### PostgreSQL backend (default)

Requires a running PostgreSQL/PostGIS instance that already contains the
boundary and raster files generated by the Spatial Sampling Application.

``` r
library(susogrdframe)

run_app(
  mapboxkey = Sys.getenv("MAPBOX_KEY"),   # optional but recommended
  pghost    = "localhost",
  pguser    = "shiny",
  pgpass    = Sys.getenv("PG_PASS"),
  pgdbname  = "spatsampdata"
)
```

### Local directory backend

No database required. Place your files in the directory structure below
and point `run_app()` at it.

    my_frame_data/
      shapefiles/     # ESRI Shapefiles (.shp + .dbf, .prj, .shx, ...)
      rasterfiles/    # GeoTIFF population rasters (.tif)

``` r
library(susogrdframe)

run_app(
  data_backend = "local",
  local_dir    = "~/my_frame_data",     # sub-dirs created automatically
  mapboxkey    = Sys.getenv("MAPBOX_KEY")
)
```

## Application workflow

Once the application is running, follow these steps in the **Application
Inputs** tab:

1.  **Load boundary file** — click *Show Existing Shape*, select a
    boundary layer, and confirm. The boundary is drawn on the
    interactive map.
2.  **Select stratification variable** — choose the column that defines
    strata (e.g. district name or land-use type).
3.  **Select stratum** — filter the boundary to a single stratum.
4.  **Load raster file** — click *Show Existing Raster* and select the
    corresponding population raster. Optionally click *Show raster
    image* for a quick preview.
5.  **Create grid cells** — click *Create Grid Cells* to overlay the
    population-weighted grid on the map. Each cell is labelled with a
    unique `GRIDID`.
6.  **Select grid cell** — pick the cell that requires a replacement
    from the dropdown. The selected cell is highlighted in red on the
    map.
7.  **Configure output** — choose whether to split the cell into
    sub-segments and whether to attach an offline basemap.
8.  **Download resources** — click *Download Survey Resources* to
    generate and download the ZIP package.

## Application settings

Switch to the **Application Settings** tab to configure:

- **Basemap service** — ESRI World Imagery, OSM, Mapbox, Bing, or ESRI
  Tile Package. Mapbox and Bing require an API key.
- **Survey Solutions API** — server URL and credentials for direct
  integration.
- **Data Storage** — read-only panel showing the active backend
  (PostgreSQL or Local Directory) and, in local mode, the resolved data
  root path.

## Runtime parameters

Full documentation for all `run_app()` parameters is available in R:

``` r
?susogrdframe::run_app
```

Key parameters at a glance:

| Parameter | Default | Description |
|----|----|----|
| `data_backend` | `"postgres"` | `"postgres"` or `"local"` |
| `local_dir` | `NULL` | Path to local data root (required when `data_backend = "local"`) |
| `mapboxkey` | `NULL` | Mapbox API key for the interactive base map |
| `bgmaptype` | `"streets"` | Mapbox style: `"dark"`, `"light"`, `"outdoors"`, `"streets"`, `"satellite"`, `"satellite-streets"` |
| `pghost` | `"localhost"` | PostgreSQL host |
| `pguser` | `"shiny"` | PostgreSQL user |
| `pgpass` | `NULL` | PostgreSQL password |
| `pgdbname` | `"spatsampdata"` | PostgreSQL database name |
| `susomapcrs` | `3857` | Output CRS for Survey Solutions shapefiles (Web Mercator) |
